# 🤖 بوت واتساب بارك ستريت الذكي لمتابعة الـ 3 شيفتات (Park Street WhatsApp Shift Bot)

يقوم هذا البوت بالارتباط بتطبيق الواتساب عبر مسح **QR Code** (مثل واتساب ويب) لمتابعة الجروبات التشغيلية الـ 5 على مدار الـ 3 شيفتات:
1. 🔧 **جروب الصيانة (Maintenance)**
2. ⚙️ **جروب التشغيل (Operations)**
3. 🛡️ **جروب الأمن (Security)**
4. 🧹 **جروب النظافة والهاوس كيبنج (Housekeeping)**
5. 🧯 **جروب السيفتي والسلامة (Safety & HSE)**

---

## 🚀 خطوات التشغيل السريع:

```bash
cd whatsapp-bot
npm install
npm start
```

1. عند تشغيل `npm start` سيظهر لك **QR Code** في نافذة الأوامر.
2. افتح تطبيق الواتساب على هاتفك ⬅️ **الأجهزة المرتبطة (Linked Devices)** ⬅️ **ربط جهاز** وامسح الكود.
3. سيقوم البوت تلقائياً بـ:
   - قراءة رسائل الجروبات وتصنيف كل رسالة حسب الجروب والفئة الفرعية والموقع والشيفت (صباحي • مسائي • ليلي).
   - ربط ردود **"تم / تم الإصلاح ✅"** بالبلاغات المفتوحة لتحديث حالتها إلى **"تم الإنجاز"** تلقائياً.
   - مزامنة جميع الأوردرات لحظياً مع لوحة **«💬 تحليل جروبات الواتساب وملخص الـ 3 شيفتات»** داخل تطبيق الويب `https://snag-app-firebase.web.app`.
   - الرد الفوري بالملخص التنفيذي الشامل داخل الجروب عند إرسال كلمة `!تقرير` أو `!ملخص`.
